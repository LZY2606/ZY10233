# 陶胎火候辨证台

基于薄片矿物、XRD 相组成、孔隙率与热改性特征，对陶胎**烧成温度 × 气氛 × 保温时间**
做联合区间辨证的本地 Web 服务。核心立场：

- 单个相的出现/消失是**区间证据**，不是精确温度点；结论保留多个可行烧成窗。
- 温度、气氛、保温时间是**联合窗**。求解全程在三维盒
  `温度区间 × 气氛集合 × 时间区间` 上做集合运算，**不**先把每个证据投影成
  三条单轴区间再取交——那会丢掉“某温度只在某气氛+某保温下成立”的条件依赖，
  产生虚假可行区（页面同时给出朴素单轴交集作为对照并高亮虚增单元）。
- 相变阈值按规则声明的**开闭端点**处理（如长时保温方解石残存域 `T < 600℃`）。
- 证据矛盾时**不扩宽规则**，而是输出最小冲突核（minimal conflict cores）、
  逐条忽略的敏感性，以及按总权重排序的最省力缓解方向。
- 受污染观测可**降权**：不参与硬排除，但其与硬可行区冲突的部分以“软张力”标注，
  不会被静默丢弃；也可完全停用。

## 技术栈

Python 3.11+ · FastAPI · NumPy · SQLite（标准库 `sqlite3`）· 原生 HTML/Canvas/JS。
无前端构建步骤。

## 安装

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
```

## 自动化测试

```bash
.venv/bin/python -m pytest -q
```

覆盖：开闭端点、present/absent 阈值互补、矛盾与最小冲突核、降权重开可行窗、
软张力保留、联合窗 vs 单轴交集虚增、规则版本切换、差集运算，以及 HTTP 层的
保存运行 → 导出 → 清空重置 → 导入 → 重放摘要复核全链路。

## 演示

```bash
.venv/bin/python -m pytest -q && .venv/bin/uvicorn app:app --host 127.0.0.1 --port 5573
```

浏览器访问 <http://127.0.0.1:5573>，页面标题为**陶胎火候辨证台**。

建议的验收动线（对应固定样品 `NC-01`）：

1. 打开即为矛盾态：受污染的方解石存在观察（`o1`，边缘重结晶、疑似埋藏污染）
   与莫来石/伊利石消失/强烈玻化三条高温证据分别构成最小冲突核
   `{o1,o2} {o1,o4} {o1,o5}`；联合可行窗为空，系统不扩宽规则。
2. 对 `o1` 点“降权”：联合窗恢复为
   `氧化，T∈[950,1300]℃，保温∈[2,16]h` 与
   `氧化，T∈[1000,1300]℃，保温∈[0.1,2)h` 两段；
   同时 `o1` 的软张力区域在图上以琥珀色标出。
3. 切换规则版本 `v1 → v2`（莫来石阈值上修 950→1000℃），可行窗整体收缩。
4. 切到对照样 `NC-02`：联合窗为空，但朴素单轴交集虚增 192 个参数单元
   （图中黄褐色描边），直观看多维依赖不能拆成单轴。
5. “敏感性”表显示只有忽略 `o1` 能解除冲突；忽略其他高温证据无效。

## 数据口径

- 参数域：温度 `[300,1300]℃`；气氛 `O 氧化 / R 还原 / N 中性`；
  保温 `[0.1,16] h`。
- 规则包固定在代码中：`app/rules.py`。每条规则的可行域是若干带开闭端点的
  三维盒，且按“原料 × 气氛 × 保温”组合限定温度。
  - `v1` 为初版；`v2` 为修订版（仅莫来石阈值变化），用于版本切换敏感性。
  - 数值为**教学型 fixture**，演示区间辨证方法，不替代真实考古定年。
- 样品与观测同样是固定 fixture：
  - `NC-01`：含争议方解石的泥质陶片（1 条污染观察 + 5 条确认观察）。
  - `NC-02`：联合窗对照样（高温氧化长时 vs 低温还原短时）。
- 数据库（`data/pottery.db`，可用环境变量 `POTTERY_DB_PATH` 覆盖）只存**可变状态**：
  样品、观测权重、求解运行记录（含当时观测快照与结论摘要）、人工解释分支；
  规则包不入库，保证重放时规则版本可追溯。

## 计算方法（`app/solver.py`）

1. 精确盒代数：区间交/差显式处理开闭；盒并集交（distribute）后去包含、
   仅在两轴完全同构时合并相邻盒，绝不跨气氛/时间段拼合。
2. 签名栅格：收集所有盒端点与各开段中点，构造对“空/非空”判定精确等价的
   细栅格，用 NumPy 布尔掩码快速枚举；代码内含断言，保证栅格结论与精确盒一致。
3. 最小冲突核：每个不可行栅格单元给出一个“被违反证据集”，冲突族的
   **最小命中集**即最小冲突核（Reiter 命中集树递归 + 包含剪枝）；
   按 `(总权重, 基数)` 排序。
4. 展示栅格：温度 20℃/格、保温 0.5h/格，仅用于 Canvas 绘制与悬停。
5. 复核摘要：对结论性字段（可行盒、冲突核、张力、朴素虚增数）做规范化 SHA-256，
   重放时逐字段一致才判定复核通过（掩码是派生展示量，不参与摘要）。

## 运行记录、分支与清空复核

- “保存运行记录”：保存当前规则版本、观测权重快照与完整求解结果
  （`POST /api/samples/{id}/solve` 带 `save:true`）。
- “存为人工解释分支”：把当前人工权重选择固化为命名分支，保留多种解释并存。
- “导出运行记录”：下载全量 JSON（样品/观测/运行/分支）。
- “清空并重置 fixture”：清空所有可变数据并恢复固定样品与观测。
- 选择导出文件后“导入复核”：整库导入，随后可对任意运行点“重放”，
  比对存储摘要与重放摘要是否一致。

### 命令行复核示例

```bash
# 导出
curl -s http://127.0.0.1:5573/api/export -o export.json
# 清空重置
curl -s -X POST http://127.0.0.1:5573/api/admin/reset
# 导入（需要把 export.json 包成 {"data": ...}）
.venv/bin/python - <<'PY'
import json, httpx
data = json.load(open("export.json"))
print(httpx.post("http://127.0.0.1:5573/api/import", json={"data": data}).json())
PY
# 重放某条运行
curl -s -X POST http://127.0.0.1:5573/api/runs/<run_id>/replay
```

## 目录结构

```
app/
  domain.py    区间/开闭端点/盒/规则包/观测领域模型
  solver.py    盒代数、签名栅格、联合窗求解、最小命中集冲突核、敏感性
  rules.py     固定规则包 v1/v2 与固定样品 fixture
  db.py        SQLite schema、播种、全量导出/清空/导入
  services.py  求解编排与复核摘要
  main.py      FastAPI 路由与静态页
  static/      操作页面（index.html, app.js）
tests/         求解器与 HTTP 端到端测试
data/          运行态 SQLite（自动创建）
```
